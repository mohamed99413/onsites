# Discover Egypt

A responsive tourism landing page showcasing Egyptian destinations through image galleries, city cards, and dedicated destination details.

## ✨ Features

- Responsive navigation bar
- Hero section for the tourism brand
- Bootstrap image carousel
- Destination cards
- Dedicated city details page
- Responsive layout using Bootstrap grid
- Local image assets for Egyptian destinations

## 🛠️ Tech Stack

- HTML5
- CSS / Bootstrap 5
- JavaScript
- Bootstrap Carousel

## 📍 Destinations

The project includes visual content for destinations such as:

- Sharm El Sheikh
- Hurghada
- Aswan
- Port Said
- Alexandria
- Dahab
- El Galaa
- Luxor
- The Pyramids
- Egyptian Museum
- Avenue of the Sphinxes

Open `Design files/index.html` directly in a browser, or serve the folder with a local development server.

## 🎯 What This Project Demonstrates

This project demonstrates foundational frontend skills: semantic HTML structure, responsive Bootstrap layouts, reusable visual patterns, image-based UI, navigation between pages, and responsive design.
