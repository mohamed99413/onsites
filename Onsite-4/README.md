# Product Catalog Web App

A responsive product catalog built with React, focused on reusable components, client-side routing, product browsing, and a clean user experience.

## ✨ Features

- Browse a product catalog
- Product details pages with dynamic routes
- Responsive navigation and layout
- About and Contact pages
- Reusable React components
- Client-side routing with React Router
- API requests with Axios
- Loading states and user-friendly alerts
- Online/offline detection support

## 🛠️ Tech Stack

- React 19
- Vite
- JavaScript (ES6+)
- React Router
- Axios
- Bootstrap
- Tailwind CSS
- SweetAlert2
- React Spinners
- React Helmet

## 📁 Project Structure

```text
src/
├── components/     # Reusable UI components
├── context/        # Shared application state
├── pages/          # Page-specific styles
├── assets/         # Static assets
├── App.jsx         # Application routes and layout
├── About.jsx       # About page
├── Contact.jsx     # Contact page
└── main.jsx        # Application entry point
```

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/mohamed99413/onsites.git
cd onsites/Onsite-4
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```
